# PokéValue Pro

Application web responsive permettant de repérer, filtrer, comparer et organiser des cartes Pokémon de valeur.

## Fonctionnalités

- Catalogue de cartes avec recherche et filtres
- Fiches détaillées avec fourchettes de prix indicatives
- Favoris persistants dans le navigateur
- Collection personnelle persistante
- Estimateur rapide de lots
- Guide d’authentification et d’achat
- Mode clair / sombre
- Responsive mobile, tablette et ordinateur

## Installation

```bash
npm install
npm run dev
```

Puis ouvrir `http://localhost:5173`.

## Build production

```bash
npm run build
npm run preview
```

## Important

Les prix contenus dans cette version sont **des valeurs indicatives de démonstration**, non reliées à une API en temps réel. Avant tout achat ou toute revente, comparez plusieurs ventes réellement terminées pour la même langue, la même édition et le même état.
